# FRAMEORA Website

A responsive, premium black-and-silver portfolio site for FRAMEORA.

## Files
- `index.html` — site content and structure
- `style.css` — responsive layout and visual design
- `script.js` — mobile navigation and current year

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, or open the folder in VS Code and use Live Server.

## Before publishing
- Replace the illustrative Unsplash portfolio images with your own footage thumbnails/stills.
- Confirm the Instagram link `https://www.instagram.com/frameora.editss/`.
- Update the location if needed.
- If you add email or WhatsApp contact, use your intended public business contact details.
- This version uses Google Fonts and remotely hosted Unsplash images, so internet access is needed for those assets.

## Easy hosting
You can publish this static site with GitHub Pages, Netlify, or Vercel. No backend is required.
